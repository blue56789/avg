# Average Calculator

A simple tool to calculate the average (mean) of a list of numbers.

## Features

- Intuitive keyboard navigation
- Ability to input a list of numbers without entering a delimiter (like a comma)

## Usage

- Start typing a number
- Press **Enter** to add a new input
- Use **Up** and **Down** arrow keys to navigate through the inputs
- Press **Backspace** on an empty input to delete it
